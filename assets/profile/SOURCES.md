# Profile picture

The portfolio owner supplied this profile picture from a Facebook CDN link on 2026-10-19. `avatar.jpg` preserves the downloaded 334 × 334 JPEG. It is served locally; the website does not depend on the temporary Facebook URL.

The self-contained `../icons/favicon.svg` embeds the same JPEG with a rounded-square display mask. Header and About avatars use the local JPEG directly. When changing the avatar, update the JPEG and the embedded favicon together.
